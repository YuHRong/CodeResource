# Review

1. What is a computation? 

计算是只数据从输入到输出的过程，例如计算两个数的和，输入两个数，在输入之后通过计算两个数的和并输出，在这过程中称为计算。

2. What do we mean by inputs and outputs to a computation? Give examples. 

例如计算 `2`的平方，从键盘输入`2`,在计算机屏幕上打印 `4`

- `Correctly`: 正确
- `Simply`: 简单
- `Efficiently`: 高效`

4. What does an expression do? 

表达式是程序的基本组成单元，表达式就是从一些操作数计算值。最简单的表达式是字面常量例如10，'a'，3.14和"Norah"。 

5. What is the difference between a statement and an expression, as described in this chapter? 

语句是将表达式组织起来进行计算，也就是说，语句是表达式组合而成的。
