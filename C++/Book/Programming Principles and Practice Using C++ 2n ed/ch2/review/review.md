1. “Hello，World！”程序的目的是什么？ 

这是每个学习编程的程序员学习的第一个经典小程序，目的让初学者能够很好的进入编程领域。

2. 说出一个函数的4个部分。 
- `返回类型`，他用来表示返回结果的类型。
- `函数名`称，在其他地方调用该函数的名字。
- `参数列表`，放在()圆括号中的内容。
 - `函数体`，使用 {} 花括号括起来的执行语句。

3. 说出必须出现在每个C++程序中的一个函数。
- main()`函数，代表程序的入口。

4. 在“Hello，World！”程序中，return0；这行的目的是什么？ 

表示程序执行完成， `return 0`返回0给`main()`函数中止运行程序。

5. 编译器的目的是什么？ 

编译器可以链接C++库，使源代码文件编译成可执行文件。

6. #include语句的目的是什么？ 

他是一个包含语句，后跟需要包含在该源代码中的头文件。

7. 文件名后缀为.h在C++中表示什么？ 

后缀名为`.h`的文件是头文件，他里面包含了 C++执行需要的函数方法等。

8. 链接器为你的程序做什么？ 

将源文件中头文件中的个函数链接起来并编译成可执行文件。

9. 源文件和目标文件之间的区别是什么？ 

源文件是程序员编写的代码文件，是程序员给计算机的指令，目标文件是让计算机执行的二进制文件。

10. IDE是什么？它能为你做什么？

`ide`可以编写源文件，并使链接器编译源文件，最后执行程序的工具。**注**：`ide`还可以给程序做调试。

11. 即使你理解教材中的所有东西，为什么还是需要实践？ 

只有实践才能更好巩固所学的知识，才能更好吸收为你所用。
