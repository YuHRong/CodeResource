# 动态内存管理 （new 和  delete）

## 内存区域概述
C++程序中的内存分为两个主要部分：
- `栈（Stack）`：用于存储局部变量，函数调用时的参数等。栈内存由系统自动管理，在函数返回时自动释放。
- `堆（Heap）`：用于动态分配内存，程序员可以在运行时申请和释放这部分内存。

## 动态内存分配与释放
C++提供了 `new` 和 `delete` 运算符，用于在堆中分配和释放内存。使用 `new` 运算符可以在堆中为变量动态分配内存，而使用 `delete`  运算符可以释放这些内存。

#### 动态分配内存：`new`运算符
`new`  运算符用于在堆中动态分配内存，并返回一个指向该内存的指针。
```c++
int* ptr = new int;  // 为一个int类型的变量分配内存
```

#### 释放内存：`delete`运算符
`delete`  运算符用于释放之前通过 `new` 分配的内存。
```c++
delete ptr; // 释放指针ptr指向的内存
```

### 数组的动态内存分配
使用 `new` 可以为数组动态分配内存。
```c++
 int *arr = new int[10]; // 为一个包含10个整数的数组分配内存
 delete[] arr;           // 释放数组内存
```

### 对象的动态内存分配
`new`  和 `delete`  同样适用于对象。为对象分配内存时，会调用构造函数，释放内存时，会调用析构函数。
```c++
class Box
{
public:
 Box() { std::cout << "调用构造函数！" << std::endl; }
 ~Box() { std::cout << "调用析构函数！" << std::endl; }
};

int main()
{
 Box *myBox = new Box(); // 动态分配 Box 对象，调用构造函数
 delete myBox;           // 释放内存，调用析构函数

 Box *myBoxArray = new Box[4]; // 动态分配Box对象数组，调用4次构造函数
 delete[] myBoxArray;          // 释放数组内存，调用四次析构函数

 return 0;
}
```

## delete[] 和delete的区别
在C++中， `delete` 和 `delete[]` 都是用于释放通过 `new` 和 `new[]` 运算符动态分配的内存。然而，它们之间有一个重要的区别： `delete`  用于释放单个对象的内存，而`delete[]` 用于释放数组的内存。

### delete  的使用
```c++
`delete`用于释放通过`new`运算符分配的单个对象
```c++
int *ptr = new int; // 动态分配一个int类型的对象
delete ptr; // 释放这个对象的内存
```
当使用`delete`时，会调用指针指向对象的析构函数（如果有），然后释放内存。

### delete[] 的使用
```delete[]`用于释放`new[]`分配的数组。
```c++
int *arr = new int[10]; // 动态分配一个包含10个int的数组
delete[] arr; // 释放这个数组的内存
```
当使用`delete[]`时，会调用数组中每个对象的析构函数（如果有），然后释放整个数组的内存。

### 为什么需要区别对待？
C++需要区分 `delete`和 `delete[]`是因为编译器  需要知道它是在释放`单个对象`还是`多个对象`，以便正确地调用相应的`析构函数`。
- 对于单个对象：编译器只需要调用一次析构函数并释放内存。
- 对于数组：编译器需要调用数组中每个对象的析构函数，然后释放整个数组的内存。

如果错误地使用 `delete`来释放数组内存，或者使用 `delete[]` 来释放单个对象内存，结果是未定义的行为，可能会导致程序崩溃或其他不可预测的问题。
- `delete`：用于释放通过 `new`分配的单个对象。
- `delete[]`：用于释放通过 `new[]`分配的数组。

## 常见的动态内存管理问题
-  `内存泄漏`：如果程序没有释放通过 `new`分配的内存，将导致内存泄漏。内存泄漏会逐渐耗尽系统资源，导致程序或系统的性能下降。
-  `野指针`：释放内存后指针仍然指向该内存，称为野指针。访问野指针指向的内存会导致未定义行为。
