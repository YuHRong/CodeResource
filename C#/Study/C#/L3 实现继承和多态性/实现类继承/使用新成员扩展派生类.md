派生类用于扩展或修改其继承的基类。<br>创建派生类时，可以使用多个选项来扩展基类：
- 可以在基类中不存在的派生类中定义新属性和方法。 此选项允许通过在派生类中提供更多功能来扩展基类的行为。
- 可以在与基类中的属性和方法同名的派生类中定义属性和方法。 在这种情况下，可以使用`new`关键字隐藏基类成员。
- 可以在派生类中定义属性和方法，以替代基类中的属性和方法。 在这种情况下，可以使用`override`关键字来扩展或修改基类成员的行为。

还可以使用`new`关键字避免意外重写基类成员。 使用`new`关键字可确保派生类成员被视为单独的实体。

---

将新成员添加到基类中不存在的派生类

创建派生类时，可以添加新的属性和方法来扩展基类的行为和功能。 但是，需要管理或避免基类和派生类之间的命名冲突。

请看下面示例： 

```c#
// create instances of the base class and the derived classes
BaseClass baseClass = new BaseClass();
DerivedClass derivedClass = new DerivedClass();
BaseClass baseClassReferencingDerivedClass = new DerivedClass();

// access properties and methods of the base class
Console.WriteLine($"\n{baseClass.Property1}");
baseClass.Method1();

// access properties and methods of the derived class
Console.WriteLine($"\n{derivedClass.Property1}");
derivedClass.Method1();
Console.WriteLine($"{derivedClass.Property2}");
derivedClass.Method2();

// access properties and methods of the base class that references the derived class
Console.WriteLine($"\n{baseClassReferencingDerivedClass.Property1}");
baseClassReferencingDerivedClass.Method1();
//baseClassReferencingDerivedClass.Method2(); //Generates error: 'BaseClass' doesn't contain a definition for 'Method2' ...

/*Output:
Base - Property1
Base - Method1

Base - Property1
Base - Method1
Derived - Property2
Derived - Method2

Base - Property1
Base - Method1
*/

public class BaseClass
{
    public string Property1 { get; set; } = "Base - Property1";

    public void Method1()
    {
        Console.WriteLine("Base - Method1");
    }
}

public class DerivedClass : BaseClass
{
    public string Property2 { get; set; } = "Derived - Property2";

    public void Method2()
    {
        Console.WriteLine("Derived - Method2");
    }
}
```

此代码示例包括顶级语句和两个类：`BaseClass` 和 `DerivedClass`。 `BaseClass` 类定义一个名为 `Property1` 的属性和一个名为 `Method1` 的方法。 派生类 `DerivedClass` 使用名为 `Property2` 的新属性和名为 `Method2` 的新方法扩展基类。 基类和派生类之间没有命名冲突，因此可以从派生类的实例访问新的和继承的成员。

该代码创建名为 `BaseClass` 的 `baseClass` 实例，以及名为 `DerivedClass` 的 `derivedClass` 实例。 该代码还会创建引用 `BaseClass` 实例的名为 `baseClassReferencingDerivedClass` 的 `DerivedClass` 实例。 然后，该代码完成以下步骤：
- 它使用 `baseClass` 来显示 `Property1` 的值并调用 `Method1` 。
- 它使用 `derivedClass` 来显示 `Property1`  、调用 `Method1` 、显示 `Property2` 的值和调用 `Method2` 的值。
- 它使用 `baseClassReferencingDerivedClass` 调用 `Method1` 并显示 `Property1` 的值。

请注意，变量 `baseClassReferencingDerivedClass` 声明为类型 `BaseClass` ，但分配了 `DerivedClass` 类型的实例。 使用此声明语法意味着，即使 `baseClassReferencingDerivedClass` 对象包含派生类的引用，它也仍被视为基类的实例。 `尝试调用 `Method2` 将导致编译时错误，因为基类没有名为 `Method2` 的方法。 当应用将对象实例化为基类类型，然后为对象分配派生类实例时，它已准备好实现多态性。 虽然类继承通常用于支持多态性，但继承和多态性是不同的主题。

运行代码时，会看到以下输出：

```plaintext
Base - Method1

Base - Property1

Base - Method1

Base - Property1

Derived - Method2

Derived - Property2

Base - Method1

Base - Property1
```

基类对象 `baseClass` 和 `baseClassReferencingDerivedClass` 只能访问基类中定义的属性和方法。 派生类对象 `derivedClass` 可以访问基类和派生类中的属性和方法。

## 将新成员添加到基类中存在的派生类 分组

向派生类添加新成员时，需要注意基类和派生类之间的命名冲突。 当派生类定义与基类中的成员同名的成员时，会发生命名冲突。
请看下面代码示例，其中包含基类和派生类之间的命名冲突：

```c#
// create instances of the base class and the derived classes
BaseClass baseClass = new BaseClass();
DerivedClass derivedClass = new DerivedClass();
BaseClass baseClassReferencingDerivedClass = new DerivedClass();

// access properties and methods of the base class
Console.WriteLine($"\n{baseClass.Property1}");
Console.WriteLine($"{baseClass.Property2}");
baseClass.Method1();
baseClass.Method2();

// access properties and methods of the derived class
Console.WriteLine($"\n{derivedClass.Property1}");
Console.WriteLine($"{derivedClass.Property2}");
derivedClass.Method1();
derivedClass.Method2();

// access properties and methods of the base class that references the derived class
Console.WriteLine($"\n{baseClassReferencingDerivedClass.Property1}");
Console.WriteLine($"{baseClassReferencingDerivedClass.Property2}");
baseClassReferencingDerivedClass.Method1();
baseClassReferencingDerivedClass.Method2();

/*Output:
Base - Property1
Base - Property2
Base - Method1
Base - Method2

Base - Property1
Derived - Property2
Base - Method1
Derived - Method2

Base - Property1
Base - Property2
Base - Method1
Base - Method2
*/

public class BaseClass
{
    public string Property1 { get; set; } = "Base - Property1";
    public string Property2 { get; set; } = "Base - Property2";

    public void Method1()
    {
        Console.WriteLine("Base - Method1");
    }

    public void Method2()
    {
        Console.WriteLine("Base - Method2");
    }
}

public class DerivedClass : BaseClass
{
    public string Property2 { get; set; } = "Derived - Property2";

    public void Method2()
    {
        Console.WriteLine("Derived - Method2");
    }
}
```

请注意，派生类中的 `Property2` 和 `Method2` 的名称与基类中的 `Property2` 和 `Method2` 相同。 复制成员会在基类和派生类之间创建命名冲突。 生成解决方案将生成一条警告，指出派生类的成员隐藏从基类继承的成员。

```
warning CS0108: 'DerivedClass.Property2' hides inherited member 'BaseClass.Property2'. Use the new keyword if hiding was intended.

warning CS0108: 'DerivedClass.Method2()' hides inherited member 'BaseClass.Method2()'. Use the new keyword if hiding was intended.
```

如果运行代码，则会看到以下输出：
```c#
Base - Property1
Base - Property2
Base - Method1
Base - Method2

Base - Property1
Derived - Property2
Base - Method1
Derived - Method2

Base - Property1
Base - Property2
Base - Method1
Base - Method2
```

输出显示使用声明为派生类的对象时调用派生类的 `Property2` 属性和 `Method2` 方法。 使用声明为基类的对象时，将调用 `Property2` 属性和基类的 `Method2` 方法。

如果基类和派生类之间存在命名冲突，则可以使用 `new` 关键字有意隐藏基类成员。 使用 `new` 关键字，可以在派生类中定义与基类中的成员同名的新成员。

## 使用 `new` 关键字避免命名冲突

如果基类和派生类之间存在命名冲突，则可以使用 `new` 关键字有意隐藏基类成员。 此语法允许在派生类中定义与基类中的成员同名的新成员。 以这种方式使用 `new` 关键字不会更改编译器解决命名冲突的默认行为，但它确实禁止生成解决方案时发生的警告，并有意隐藏基类成员显式。

以下代码使用派生类中的 `new` 关键字来隐藏基类中定义的`Property2` 属性和 `Method2` 方法：

```c#
// create instances of the base class and the derived classes
BaseClass baseClass = new BaseClass();
DerivedClass derivedClass = new DerivedClass();
BaseClass baseClassReferencingDerivedClass = new DerivedClass();

// access properties and methods of the base class
Console.WriteLine($"\n{baseClass.Property1}");
Console.WriteLine($"{baseClass.Property2}");
baseClass.Method1();
baseClass.Method2();

// access properties and methods of the derived class
Console.WriteLine($"\n{derivedClass.Property1}");
Console.WriteLine($"{derivedClass.Property2}");
derivedClass.Method1();
derivedClass.Method2();

// access properties and methods of the base class that references the derived class
Console.WriteLine($"\n{baseClassReferencingDerivedClass.Property1}");
Console.WriteLine($"{baseClassReferencingDerivedClass.Property2}");
baseClassReferencingDerivedClass.Method1();
baseClassReferencingDerivedClass.Method2();

/*Output:
Base - Property1
Base - Property2
Base - Method1
Base - Method2

Base - Property1
Derived - Property2
Base - Method1
Derived - Method2

Base - Property1
Base - Property2
Base - Method1
Base - Method2
*/

public class BaseClass
{
    public string Property1 { get; set; } = "Base - Property1";
    public string Property2 { get; set; } = "Base - Property2";

    public void Method1()
    {
        Console.WriteLine("Base - Method1");
    }

    public void Method2()
    {
        Console.WriteLine("Base - Method2");
    }
}

public class DerivedClass : BaseClass
{
    public new string Property2 { get; set; } = "Derived - Property2";

    public new void Method2()
    {
        Console.WriteLine("Derived - Method2");
    }
}
```

运行代码时，输出将与上一示例中的输出相同。 派生类中使用 `new` 关键字来隐藏基类中定义的 `Property2` 属性和 `Method2` 方法。 使用声明为派生类的对象时，将调用 `Property2` 属性和派生类的 `Method2` 方法。 使用声明为基类的对象时，将调用 `Property2` 属性和基类的 `Method2` 方法。

### 有关使用 `new` 关键字的一般指南 分组

`new` 关键字可用于有意隐藏基类的成员。 当派生类需要提供与基类成员不兼容的不同实现或功能时，此行为非常有用。 还可以使用 `new   关键字来确保隐藏基类成员的意图是明确的。 如果没有 `new` 关键字，则派生类成员是否旨在替代基类成员或隐藏该成员，可能还不清楚。

应用 `new`  关键字时，请使用以下准则：
- 如果要有意隐藏基类的成员，请使用`new`关键字。 隐藏基类成员可确保派生类成员被视为单独的实体。
- 如果要避免意外重写基类成员，请使用`new`关键字。 有意退出`new`关键字可能导致另一位开发人员认为应重写派生类成员。
- 如果要扩展或修改基类成员的行为，请避免使用`new`关键字。 在这种情况下，请考虑改用`override`关键字。
- 如果`new`关键字导致代码中的混淆或歧义，请避免使用。 确保隐藏基类成员的目的清晰且合理。
