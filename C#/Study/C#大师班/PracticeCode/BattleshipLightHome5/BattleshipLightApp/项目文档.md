# 战舰精简需求

## 基本需求

构建一个小型双人控制台游戏

创建一个25个网格，从 A1到A5，在从 B1 到 B5以此类推。

使用一个标记作为舰船，

1. 玩家轮流像对手开火。
1. 击沉全部5搜舰船后获胜，


使用三个地方放置内容
1. 用户见面后的控制台。
2. 类库中的逻辑。
3. 类库中的数据模型，也就是模型。

完成上述三个内容即可完成基本的应用程序。

# WOULD 框架

- `W`大致走一遍项目。粗略的从第一印象理解程序，了解程序结构。
- `o`打开需求。
- `u`及用户见面设计`user interface design`.
- `l`逻辑设计`the logic design`，思考整体设计，如何实现不同部分，考虑数据存储，考虑用户设计从哪开始。
- `d`数据设计`data design`。我们需要把数据放在一起还是把数据放在不同模型最后在连接。

## WO

走一遍项目和打开需求。

### W 走一遍项目

1. 打开控制台，
  - 两位用户使用同一个控制台还是两个控制台协同工作，又或者是通过网络进行通信（本项目不涉及网络通信）。
2. 询问用户1和用户2放置船只的位置。  
3. 询问用户1 的发射第一炮，判断这一炮是否击中用户2的船只，同时判断游戏是否结束。第一轮肯定不是。
4. 询问用户2发射第一炮的位置。判断游戏是否结束，判断是否命中，
5. 重复上述步骤直到游戏结束。
6. 确认胜利用户。退出程序。
7. 是否统计命中率以及未命中的信息。
